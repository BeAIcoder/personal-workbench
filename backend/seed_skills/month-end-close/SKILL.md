# 月末结账检查清单

> 本技能包由个人工作台种子技能库提供（seed_skills），可整目录复制修改。

## 使用方式

按顺序执行，每步完成后向用户报告结果与待办；任何一步发现异常，先记录再继续，
不要跳步。所有结论以用户提供的账表数据为准，不凭记忆补数。

## 七步流程

1. **收票**：催收各部门未报销发票，检查进项发票是否全部认证（电子税务局查验）。
2. **银行**：下载对账单，编制银行余额调节表；未达账项逐笔列出。
3. **往来**：核对应收应付明细，清理长期挂账（超过 90 天重点提示）。
4. **计提**：折旧、摊销、工资、社保、税金及附加——逐项确认计提口径与上月一致。
5. **结转**：损益结转，生成总账、明细账；检查科目余额方向异常。
6. **报表**：资产负债表、利润表勾稽核对（未分配利润变动 = 净利润 - 分红）。
7. **归档**：凭证打印装订，电子档备份（本地 + 备份盘各一份）。

## 输出

结账完成报告（Markdown）：各步状态、异常清单、待人工处理事项、下月注意事项。
