# 发票报销审核要点

> 本技能包由个人工作台种子技能库提供（seed_skills），可整目录复制修改。

## 审核清单

1. **抬头与税号**：发票抬头必须与报销单位全称一致，税号逐位核对。
2. **真伪查验**：数电票需在电子税务局查验；查验截图随凭证归档。
3. **连号识别**：同一商家连号发票关注是否拆分报销（化整为零）。
4. **附件齐全**：审批单、合同、行程单、验收单等业务附件按制度配齐。
5. **超标准**：超标准部分需部门负责人特批，特批单归档。
6. **专普票**：专票需抵扣联认证；普票仅做费用凭证。

## 输出

审核结论（通过/退回/待补充）+ 问题清单 + 整改建议。结论只基于本次实际看到的发票与附件。
