# 数据模板 / 使用速查

> 每份模板对应一个上传入口，格式按各模块解析代码 + `脱敏数据/` 样本实测表头设计，并经端点级测试验证（`backend/tests/test_data_templates.py`）。完整字段与报错说明见仓库根目录《数据收传使用说明.md》。

## 模板 ↔ 入口对照（10 份）

| 模板文件 | 上传入口（页面） | 怎么用 |
|---|---|---|
| `数据仓-入仓模板.csv` | 财务▸数据仓▸表清单「上传入仓」 | 列不限，第一行=表头；表名小写字母/数字/下划线；模式「整表重建/追加」 |
| `数据仓-入仓模板.xlsx` | 财务▸数据仓▸表清单「上传入仓」 | 同上，xlsx 版；可指定工作表 |
| `个人记账-导入模板.csv` | 个人记账页「导入 CSV」 | 表头固定：日期/类型/金额/账户/分类/备注；类型只能「收入/支出」 |
| `费用分类-银行存款辅助明细账-模板.xlsx` | 费用分类页上传；现金流页（当「银行存款辅助明细账」用） | 表头行自动定位；引擎只统计科目编码前缀 100201 的行 |
| `POS对账-认领记录-模板.xlsx` | POS 对账「上传」 | 文件名已含「认领记录」关键词，**填完不要重命名**，直接上传 |
| `POS对账-辅助明细账-模板.xlsx` | POS 对账「上传」 | 同上（引擎只取科目名称含「第三方支付平台_POS」或编码 10120803 的行） |
| `POS对账-凭证列表-模板.xlsx` | POS 对账「上传」（可选输入） | 同上；对账凭证侧 |
| `BIP账簿-凭证列表-模板.xlsx` | 企业记账 BIP「上传」 | 一次一个文件、一个文件一个类型；凭证续行日期/凭证号留空自动沿用 |
| `BIP账簿-辅助明细账-模板.xlsx` | 企业记账 BIP「上传」 | 每行自带日期，不 ffill；同凭证按金额签名合并进已有凭证 |
| `BIP账簿-辅助余额表-模板.xlsx` | 企业记账 BIP「上传」 | 确认入库时必须填期间 `YYYY-MM`；按（账簿, 期间, 科目）upsert |

> **银行流水模板没有静态文件**：在「财务▸账务处理▸银行流水模板」上传流水后按账户/日期区间生成。程序内置骨架 `backend/app/modules/finance_bankflow/template_skeleton.xlsx` 是格式来源，**不要手改、不要替换、不要用 Excel 另存覆盖**；要改格式请改代码并补格式回归测试。

## 四个提醒

1. 示例行（标记「示例-请替换」）填完请替换/删除后上传；模板列结构不要改动，**加列可以，删列/改表头词要先对照《数据收传使用说明.md》对应章节**。
2. POS / 现金流引擎按**文件名关键词**找文件，模板文件名就是钥匙，**不要重命名**。
3. BIP 三份模板**不要合并进一个工作簿**：预览是整文件识别单一类型，三合一会导致类型识别混乱。
4. 通用限制：单次 ≤200,000 行；单文件大小 5/10/20/50MB 按模块不同（全局请求体 128MB）；CSV 编码 UTF-8/GBK 均可；报错对照《数据收传使用说明.md》§13 速查表。
