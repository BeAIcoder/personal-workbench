# 数据模板 / 使用速查

> 每份模板对应一个上传入口，格式按各模块解析代码 + `脱敏数据/` 样本实测表头设计，并经端点级测试验证（`backend/tests/test_data_templates.py`）。完整说明见仓库根目录《数据收传使用说明.md》。

## 模板 ↔ 入口对照

| 模板文件 | 上传入口（页面） | 怎么用 |
|---|---|---|
| 数据仓-入仓模板.csv / .xlsx | 财务▸数据仓▸表清单「上传入仓」 | 列不限，第一行=表头；表名小写字母/数字/下划线；模式「整表重建/追加」 |
| 个人记账-导入模板.csv | 个人记账页「导入 CSV」 | 表头固定：日期/类型/金额/账户/分类/备注；类型只能「收入/支出」 |
| 费用分类-银行存款辅助明细账-模板.xlsx | 费用分类页上传；现金流页（当「银行存款辅助明细账」用） | 表头行自动定位；引擎只统计科目编码前缀 100201 的行 |
| POS对账-认领记录-模板.xlsx | POS 对账「上传」 | 文件名已含「认领记录」关键词，**填完不要重命名**，直接上传 |
| POS对账-辅助明细账-模板.xlsx | POS 对账「上传」 | 同上（引擎只取科目名称含「第三方支付平台_POS」或编码 10120803 的行） |
| POS对账-凭证列表-模板.xlsx | POS 对账「上传」（可选输入） | 同上；对账凭证侧 |
| BIP账簿-凭证列表-模板.xlsx | 企业记账 BIP「上传」 | 一次一个文件；凭证续行日期/凭证号留空自动沿用 |
| BIP账簿-辅助明细账-模板.xlsx | 企业记账 BIP「上传」 | 每行自带日期，不 ffill |
| BIP账簿-辅助余额表-模板.xlsx | 企业记账 BIP「上传」 | 确认入库时必须填期间 YYYY-MM |

## 三个提醒

1. 示例行（标记「示例-请替换」）填完请替换/删除后上传；模板列结构不要改动，**加列可以，删列/改表头词要先对照《数据收传使用说明.md》对应章节**。
2. POS / 现金流引擎按**文件名关键词**找文件，模板文件名就是钥匙，别改名。
3. 通用限制：xlsx/csv，单次 ≤20 万行；单文件大小上限 5-50MB 按模块不同；CSV 编码 UTF-8/GBK 均可。报错对照《数据收传使用说明.md》§12 速查表。
