# 逆向分析 · 使用说明（2026-10-12，v1.14.0  consolidate）

> 从 `使用说明.md`、各模块开发记录、API.md 合并重构的完整使用手册。

## 1. 启动与停止

- **日常**：双击 `启动工作台.bat`（自动建 venv、装依赖、起服务 :8000 并打开浏览器）；停止：`停止服务.bat` 或关闭后端窗口
- **开发**：`开发模式.bat`（8000 reload + Vite :5173）
- **备份**：`备份数据.bat`（SQLite 在线热备，留 30 份）；每周备份计划任务 VaultWeeklyBackup（AssetLib级，10-11 起恢复正常）

## 2. 菜单导航

- **基础**：概览 / 任务 / 日程 / 笔记 / AI 助手 / 定时任务
- **知识与记忆**：RAG 笔记检索（索引统计/重建）+ 长期记忆管理（新建/置顶/编辑/删除/关键词过滤）
- **MCP 工具**：stdio 服务器管理（增删改/连接/测试调用/env 脱敏）；连接后工具以 `mcp_<srv>__<tool>` 出现在专家白名单
- **技能包**：SKILL.md 技能包管理（查看/启停/新建/删除/重扫）；AI 助手设置里把技能目录指向 `backend/data/skills` 即注入 Agent
- **专家团文件**：专家 .md 导入数据库（upsert）/ 数据库导出为文件 / 从种子重置
- **财务组**（按常用度）：费用分类 / 发票处理 / 数据仓 / 个人记账 / 企业记账(BIP) / 企业所得税 / 报表看板 / 现金流填报 / POS 对账

## 3. 财务模块速查

| 模块 | 用法 | 产物 |
|------|------|------|
| 费用分类 | 上传银行明细账 xlsx → 自动分类 | 汇总图 + 结果 xlsx |
| 发票处理 | 上传 PDF/ZIP → 解析 → 修正项目归类 → 导出 | 重命名 PDF + 清单 xlsx + ZIP |
| 数据仓 | 上传 xlsx/csv 入仓 → 只读 SQL | 查询结果 + CSV 导出 |
| 个人记账 | 快速记账 → 流水筛选 → 统计 | 月度收支/分类图表、CSV |
| 企业记账(BIP) | 上传三类 BIP 导出 → 识别 → 入库 → 查询 | 凭证/分录/科目汇总、可入仓 |
| 企业所得税 | 新建企业 → 税额计算 → 保存申报 → 预览/导出 | 计算过程 + 申报记录（Excel/PDF） |
| 报表看板 | 点「运行管线刷新」（约 2 分钟）或建 Cron 定时任务 | 内嵌看板 + 历史快照 |
| 现金流填报 | 上传输入(或 ZIP) → 建运行 → 执行 | 已填报模板 + 报告（ZIP） |
| POS 对账 | 上传四份输入(或 ZIP) → 执行 | 台账 + 差异分析（ZIP） |

## 4. AI 助手

- **专家团队**：13 位（界面可增删改）；财税专员已预置全部财务模块工具（白名单自动并入）
- **工具白名单**：专家详情里勾选；MCP/技能/模块工具都在同一清单
- **定时任务**：interval/daily/**cron**（五段表达式）+ **模块动作**（如 finance_board.run 定时刷新看板，不走 LLM）
- **记忆**：对话前自动注入相关记忆 Top3；「从对话抽取」在知识与记忆页手动触发
- **模型管理**：供应商预设 18 家一键填充；模型能力探测（思考级别/上下文/输出长度）；模型级 temperature/备注/思考手动覆盖

## 5. 排障指针

- 引擎不可用（费用分类/发票/现金流/POS）→ 检查AssetLib目录未移动，或按 `注意事项.md` 第 10 节配置引擎路径
- 模型报错 502 → 换模型或核对 Key/base_url；探测显示「不可达」时先修连通性
- 数据仓 SQL 被拒 → 检查是否 SELECT-only、表是否已注册、是否超限流
- 完整 FAQ 见 `注意事项.md`（12 节）与 `使用说明.md`
