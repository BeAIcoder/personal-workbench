# 项目全面检查报告

- 检查日期：2026-10-12
- 项目：Personal Workbench 个人财税自动化工作台
- 当前版本：v1.14.0（本次检查后发布 v1.15.0）

## 一、项目定位

Windows 本机单人 Web 工作台：任务/日程/笔记/搜索/仪表盘五大个人事务功能 + 基于 AgentScope 的可配置 AI 专家团队（13 位内置专家、18 家 LLM 厂商预设）+ 通过自建 Module Registry 插件机制集成的 9 个财务业务模块。数据存于单个 SQLite 文件，服务只监听 127.0.0.1，数据不出本机。

## 二、技术架构

| 层 | 技术 |
|---|---|
| 前端 | Vue 3.4 + Vite 5 + Element Plus 2.7 + echarts + ag-grid（无 Pinia，hash 路由，SSE 手写流式解析） |
| 后端 | FastAPI 0.141 + SQLAlchemy 2.0 + Pydantic 2，uvicorn 单端口 8000 托管前端 dist |
| AI | AgentScope 2.0.7（钉死）多智能体 ReAct 编排；四级路由（指定>关键词>LLM>默认） |
| 数据 | SQLite 单文件（35 张表，`mod_` 前缀隔离模块表）+ DuckDB 数据仓 |
| 安全 | pywin32/DPAPI 加密 API Key（硬依赖）；上传白名单；zip-slip 防护；vault SQL SELECT-only |

## 三、核心子系统

1. **Module Registry**：加模块 = 加目录（后端 manifest 五件套 + 前端 glob 自动注册）；四级接入策略 L0 直挂 / L1 薄壳 / L2 嵌入 / L3 登记；单模块失败不拖垮宿主。
2. **9 个财务模块**（`/api/finance/*`）：发票处理、费用分类、个人记账、企业记账 BIP、企业所得税、数据仓、报表看板、POS 台账、现金流填报（含真实数据，本地保留）。
3. **AI Agent 团队**：长期记忆 + BM25 RAG + 自实现 MCP stdio 客户端 + SKILL.md 技能包 + 专家包文件化 + 模型能力三档探测（reasoning/上下文二分/输出阶梯）+ 自实现五段 cron 定时调度。
