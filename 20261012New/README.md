## 存放约定

1. **文档/ADR/进度/测试报告/模板/脚本** → 一律放本目录对应子目录，命名带日期（如 `progress/阶段一验收_2026-10-15.md`）。
2. **业务代码的落点**：要能运行就必须在宿主应用树内——后端模块在 `backend/app/modules/<name>/`，前端模块在 `frontend/src/modules/<name>/`。本目录放的是**工程产物**而非运行时代码。
   - 例外预留：若希望后端模块代码也物理独立存放，Module Registry 支持配置额外扫描目录即可指向本目录（阶段一开工时定，记录在 adr/）。
3. **git 卫生**：本目录在 personal-workbench 仓内（GitHub 公开仓）。文档类默认可提交；**凡含真实业务值、真实数据、现金流 V1 相关产物的内容一律不进 git**（写入 `.gitignore`），提交前跑一遍 FSSC 同款脱敏自检口径。
4. **改动宿主代码时同步 6 件套文档**（spec / progress / 使用说明 / 注意事项 / API / README），并在本目录 progress/ 留验收记录。
5. 新增依赖红线：仅 MIT / Apache-2.0 / BSD（选型清单见主方案第四节）。
